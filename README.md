# Monthly Know

面向品牌营销与行业研究的可追溯情报库。项目正在从静态展示页迁移为“采集 → 存储 → 审核 → 展示”的数据系统。

## 当前能力

- GitHub Pages 静态看板与现有研究内容
- Supabase PostgreSQL 数据模型及行级访问控制
- 经审核事件的 REST API 读取与静态数据降级
- RSS/Atom 定时采集、内容哈希去重和失败隔离
- GitHub Actions 每 6 小时采集一次
- 原始证据、事件、洞察及证据关系分层存储

## 本地查看

直接在浏览器中打开 `skill-output-dashboard.html`。未配置数据库时会显示“静态样本”，并继续使用仓库中的现有数据。

## 主要页面

- 趋势雷达
- 行业全景
- 品牌对比结论
- 策略卡
- 信息源库

## 当前运行状态

- 已配置 20 个公开信息源
- GitHub Actions 每 6 小时自动采集
- 原始内容写入 Supabase `raw_documents`
- 公开看板只读取审核通过的事件
- 当前下一优先级：审核后台“采集收件箱”

## 数据原则

- 原始证据不可被 AI 结果覆盖。
- 未审核的事件默认不在公开看板显示。
- 每条洞察都应关联原始文档。
- 社交平台数据只使用授权接口、合规服务或人工导入。
